# ts6-crier

[English](README.md)

Голосовой бот-глашатай для TeamSpeak. Подключается к серверу как обычный клиент
и по таймеру **шепчет во все каналы сразу** нужную дорожку: «через 30 секунд
босс», «лес», что угодно. Управляется командами в личку.

Работает с любым сервером TeamSpeak 6: своим на VPS, арендованным у хостера,
у друга. Бот — отдельная программа, ставить его на сам сервер не нужно.

- Ничего не надо устанавливать заранее: Node.js и ffmpeg уже внутри.
- Linux (любой обычный дистрибутив, x64 и ARM), Windows, macOS (Apple Silicon).
- Свои звуки заливаются прямо через файловый браузер TeamSpeak.

## Установка

### Вариант 1. Свой VPS, бот работает круглосуточно

Одна команда на Linux-сервере (на том же, где TeamSpeak, или на любом другом):

```bash
curl -fsSL https://raw.githubusercontent.com/X4vi3/ts6-crier/main/install.sh | sudo sh
```

Установщик скачает бота в `/opt/ts6-crier`, задаст четыре вопроса (адрес
сервера, пароль, ник, кто может командовать) и запустит его как службу
systemd. Бот будет подниматься сам после перезагрузки и падений.

Если TeamSpeak крутится на этой же машине, установщик это заметит и сам
предложит `127.0.0.1`.

### Вариант 2. Windows, запускать когда нужно

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/X4vi3/ts6-crier/main/install.ps1 | iex
```

Появится ярлык **TS6 Crier** на рабочем столе. Двойной клик — бот запущен,
закрыл окно — бот выключен. При первом запуске он спросит адрес сервера.

Без PowerShell: скачай `ts6-crier-windows-x64.zip` со страницы
[Releases](https://github.com/X4vi3/ts6-crier/releases), распакуй и запусти
`ts6-crier.exe`. Windows может показать «Система Windows защитила ваш
компьютер»: файл не подписан платным сертификатом. Нажми «Подробнее» →
«Выполнить в любом случае».

### Вариант 3. Linux или Mac, запускать когда нужно

```bash
curl -fsSL https://raw.githubusercontent.com/X4vi3/ts6-crier/main/install.sh | sh
~/ts6-crier/ts6-crier
```

Без `sudo` установщик кладёт бота в `~/ts6-crier` и ничего не запускает в
фоне. Бот работает, пока открыт терминал.

### Обновление и удаление

Обновить: запустить ту же команду установки ещё раз. Настройки, личность бота,
залитые звуки и идущие таймеры сохраняются.

```bash
curl -fsSL .../install.sh | sudo sh -s -- --uninstall   # убрать программу, данные оставить
curl -fsSL .../install.sh | sudo sh -s -- --purge       # убрать всё
```

## Права в TeamSpeak

Обычной гостевой группы хватает, чтобы бот шептал, видел файлы и ставил себе
аватарку. Если на сервере права урезаны, дай боту группу, где разрешены:

- шёпот (`i_client_whisper_power`);
- просмотр и скачивание файлов в каналах (`i_ft_file_browse_power`,
  `i_ft_file_download_power`) — для `.files` и `.set`;
- загрузка аватара (`i_client_max_avatar_filesize`) — не обязательно.

Бот занимает один слот сервера.

## Команды

Пишутся **в личку боту**. Начинаются с **точки**, а не слэша: клиент TeamSpeak
перехватывает `/` и до бота такое не доходит. Бот отвечает по-английски.

```
.jungle, .boss   запустить расписание (имя расписания из конфига = команда)
.all             запустить все расписания разом, синхронно
.stop            остановить всё          .stop jungle   остановить одно
.restart         остановить всё и завести заново с этой секунды
.status          что работает, кто запустил, сколько до следующего раза

.test <имя>      проиграть дорожку один раз
.say <текст>     сказать роботом (если установлен piper, см. ниже)

.files           аудиофайлы, залитые в каналы
.set <цель> <файл> [gong]   назначить свою озвучку
.reset <цель|all>           вернуть озвучку из конфига
.sounds          что сейчас играет по каждой цели

.channels        все каналы с ID; куда бот говорит, а где молчит
.mute <id>       заткнуть канал     .unmute <id>   вернуть
.volume [0-200]  громкость
.help
```

Если команду жмут несколько человек, второй **не сбрасывает** уже идущий
отсчёт, а получает ответ, кто и когда его запустил. Начать заново можно только
явно, через `.restart`.

По умолчанию командовать может серверная группа `Server Admin`. Сменить —
в `config.yml`, раздел `commands`, или при настройке.

## Свои звуки прямо из TeamSpeak

1. Правый клик по каналу → **Файлы**, перетащить туда mp3.
2. `.files` — бот покажет, что видит.
3. `.set jungle моя-озвучка` — назначить (имя можно не дописывать целиком).
4. `.test jungle` — послушать.

Добавь `gong`, чтобы бот положил голос на подложку-гонг:
`.set jungle голос.mp3 gong`. Тогда можно заливать голую озвучку, сводить
руками не нужно.

Файл копируется к боту, поэтому удаление из канала ничего не ломает. Все
дорожки приводятся к одной громкости. Ограничение — 30 секунд
(`uploads.max_seconds`).

## Настройка

Всё лежит в `config.yml` в папке бота: `/opt/ts6-crier/config.yml` на сервере,
`%LOCALAPPDATA%\ts6-crier\config.yml` на Windows. После правки бота нужно
перезапустить (`sudo systemctl restart ts6-crier` или закрыть и открыть окно).
Пройти вопросы заново можно так: `ts6-crier --setup`.

Каждый параметр подробно описан в комментариях в файле. Главное:

```yaml
schedules:
  boss:
    cycle: 30m            # цикл 30 минут
    repeat: false         # пройти один раз и остановиться самому
    at:
      - {after: 5m,  voice: marioboss.mp3}   # через 5 минут после команды
      - {after: 15m, voice: marioboss.mp3}

  water:
    every: 20m            # просто раз в 20 минут, бесконечно
    play: water.mp3       # файл из sounds/

combos:                   # совпали по времени — играет одна общая дорожка
  - when: [jungle, boss]
    voice: "marioboss+jungle.mp3"

whisper:
  exclude_channels: [1]   # ID каналов, где бот молчит (смотри .channels)
```

Источник звука у события: `play:` — готовая дорожка как есть, `voice:` — голос,
который бот сам положит на гонг, `say:` — текст для синтеза речи.

В комплекте пример под 30-минутную гильдейскую войну: лес на отметках 25, 20,
15, 10 и 5 минут, босс на 25 и 15. Команда `.all` жмётся за 30 секунд до
старта, дорожки говорят «через 30 секунд».

## Синтез речи (по желанию)

Команде `.say` нужен [piper](https://github.com/rhasspy/piper). Положи его
в папку бота:

```
ts6-crier/
  piper/piper             (на Windows piper/piper.exe) — из релизов piper
  voices/ru_RU-dmitri-medium.onnx
  voices/ru_RU-dmitri-medium.onnx.json   — голоса: huggingface.co/rhasspy/piper-voices
```

и перезапусти бота. Без piper всё остальное работает, просто `.say`
выключена.

## Если что-то не так

- **Не подключается.** Проверь адрес и порт (голосовой порт, по умолчанию
  9987, UDP). На арендованном сервере порт обычно не 9987, он указан в панели
  хостера.
- **`too many clones already connected`** — на сервере висит старая копия
  бота. Подожди минуту, сервер сам её выкинет.
- **Команды не работают** — бот пишет в лог `denied ... your groups: ...`.
  Выдай себе группу из `admin_groups` или впиши свою группу в конфиг.
- **`.files` пустой** — у бота нет права смотреть файлы в каналах, или каналы
  под паролем.
- **Логи:** `journalctl -u ts6-crier -f` на сервере, на Windows всё в окне
  бота.
- **Alpine Linux и очень старые системы** (glibc старше 2.28, например CentOS 7)
  не поддерживаются готовой сборкой. Там можно собрать бота из исходников.

## Из исходников

Нужны Node.js 22+ и ffmpeg в `PATH`.

```bash
npm ci
npm run build          # TypeScript -> dist/
npm start              # запуск; конфиг и данные — в корне проекта
npm run package        # архив для текущей платформы -> release/
```

Релиз: запушить тег вида `v0.2.0`. GitHub Actions соберёт архивы под все
платформы, прогонит установку на Ubuntu с настоящим сервером TeamSpeak 6 и
опубликует релиз.
