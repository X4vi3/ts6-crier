# tslib

A TypeScript client for the TeamSpeak voice protocol: handshake, encryption,
commands, voice and whisper packets.

It is a port of the protocol library (TSLib) from
[TS3AudioBot](https://github.com/Splamy/TS3AudioBot) by Splamy and
contributors, which is licensed under the
[Open Software License 3.0](https://github.com/Splamy/TS3AudioBot/blob/master/LICENSE).
ts6-crier is distributed under the same license for that reason.

Changes for ts6-crier are marked in the source with `ts6-crier patch`.
